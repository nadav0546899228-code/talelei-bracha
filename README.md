## הקמה ב-Replit (כמו באתר אור יקר)

1. מעלים את התיקייה למאגר GitHub פרטי חדש (למשל `talelei-bracha-site`) ומייבאים ל-Replit **בלי סוכן**.
2. ב-Replit: **Database → PostgreSQL** (נוצר `DATABASE_URL` אוטומטית).
3. ב-**Secrets** מוסיפים:
   - `SESSION_SECRET` - מחרוזת אקראית ארוכה
   - `GOOGLE_CLIENT_ID` - אפשר להשתמש בלקוח OAuth הקיים ב-Google Cloud, ולהוסיף לו ב-**Authorized JavaScript origins** את כתובת אתר הפיתוח ואת כתובת האתר המפורסם
   - `YEMOT_TOKEN` - לחיבור ימות המשיח (אופציונלי, אפשר בהמשך)
4. **Run** - בונה ומריץ (קובץ `.replit` מוכן). אתר הפיתוח מציג פס צהוב "אתר פיתוח", האייקון שלו מסומן בפס צהוב, ולאפליקציה המותקנת שם נפרד "טללי ברכה - פיתוח".
5. **Deploy → Autoscale** - אותן הגדרות, ומוסיפים את ה-Secrets גם לפרסום.
